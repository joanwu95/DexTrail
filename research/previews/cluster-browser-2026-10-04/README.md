# 聚合档案浏览优化

日期：2026-10-04

本轮调整首页聚合条目的浏览方式，保留纸白配色、统一砖红色标签和现有五种坐标视图。

- 聚合条目显示档案数量、公开记录的最早与最晚年份。
- 整块条目可点击，打开全部组内档案清单。
- 清单展示现有缩略图、名称、已整理的机构信息和时间依据；缺少机构信息时明确标注待补充。
- 支持独立的组内搜索，按公开记录年份从近到远排序。
- 清单内名称与图片所在整行直接进入详情页；保留地图放大入口。
- 支持 Esc 关闭、焦点返回和 Enter 重新打开。

验证：JavaScript 语法检查、地图与对比状态测试 11/11、MkDocs 严格构建均通过。浏览器检查覆盖五种视图、组内搜索与空结果、详情跳转与返回、键盘关闭、组内放大、390 px 窄屏布局。默认缩放下五种视图没有条目相互遮挡。

档案覆盖：85 款手与 1 个系统；自由度、手指构型、传动路线视图均有 86 条可定位档案；驱动规模视图 57 条可定位、29 条坐标待核；主动轴演进视图 52 条可定位、34 条坐标待核。参数未核验的档案继续通过坐标待核清单访问。

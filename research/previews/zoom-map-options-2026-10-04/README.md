# 连续缩放地图：三种交互原型

此目录为独立预览，未修改正式网站。当前正式首页仍为时间泳道版本。

数据为 85 款手、1 个系统，共 86 个现有档案。图片沿用已有 URL，未下载或生成产品图片。未知参数作为独立分类保留。预览并未重新核实技术参数。

- images.html：坐标点保留真实公开年份，图片作为避让标注在附近错开。放大后增加名称显示，悬停可查看名称。图片中心不应读作精确年份。
- expand.html：总览保留点位，点击同年同类密集区域后临时展开相关产品。展开图片的位置不代表年份或技术关系，没有连接线。预览默认打开 2026 年传动待核实区域，便于比较。
- lens.html：点击产品改变局部放大窗口的中心。窗口保留年份刻度并采用同样的图片避让位置，窗口只显示局部产品。预览默认打开 Wuji Hand 2 所在区域。

三版均支持滚轮连续缩放、拖动平移、按钮缩放、键盘方向键、搜索、传动/手指数筛选、五种分类视图。01 图片链接直接进入现有详情页；02、03 点位用于探索，局部图片与底部链接进入详情。缩放边界限制在现有时间范围，图片与点位裁剪在坐标区域内。

原型未包含完整的触屏多点缩放、探索状态持久化、图片长期可用性核查与全面无障碍优化。布局和交互方案确认后再接入正式网站。

启动：`python -m http.server 8002 --bind 127.0.0.1`，访问 http://127.0.0.1:8002/ 。

# DexTrail 地图方案预览

三个独立 HTML 原型，沿用现有纸色、炭灰与砖红配色。未修改正式网站。

- A：每款产品保持独立点位；图片与名称在有足够空间时出现，放大后逐步显示更多。总览整洁，但不能同时读到所有名称。
- B：横轴年份、纵轴传动类别，各年各类产品分别成行。名称不重叠，代价是需要横向与纵向滚动。
- C：总览显示独立点位，下方浏览带展示产品图片。点击密集区域后，同年同类产品进入浏览带，便于逐个选择。

数据来自当前生成数据集：85 款手与 1 个系统档案，共 86 个条目。图片沿用已有 URL，不下载或生成产品图片。年份含论文年份、公告年份与公开记录上界，预览不重新核实产品技术参数。

原型提供搜索、传动标签筛选、三档时间窗口、产品点选与详情链接。顶端其他视图按钮与其他类别标签为版式示意，尚未连接完整交互。正式实现需进一步处理密集点位命中、连续缩放和平移。

本地查看：在本目录运行 `python -m http.server 8001 --bind 127.0.0.1`，打开 http://127.0.0.1:8001/ 。详情链接指向现有 8000 端口网站。

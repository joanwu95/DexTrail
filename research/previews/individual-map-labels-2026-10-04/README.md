# 独立产品标签与渐进缩放

日期：2026-10-04

- 取消空间邻近聚合，每款可定位产品保留独立图片、名称与详情链接。
- 缩小时允许标签重叠；标签尺寸增长至上限后，地图与显示间距继续缩放，逐步分开。
- 同年、同类别产品采用确定的显示层次，分类视图内的偏移保留在各自类别区域中；年份横坐标不变，纵向排版位置不表示性能。
- 数值视图以小点表示真实数值坐标，标签可以纵向错位；标签与预览中保留记录值。
- 缩放上限调整为 40 倍；滚轮以鼠标位置为中心，拖动与方向键继续支持探索。
- 调整视图、搜索、窗口尺寸时重新计算显示层次；短暂不可测量的窗口尺寸不会重置地图位置。
- 更换地图状态版本，避免恢复旧聚合方式下的相机位置。

验证：13 项布局、地图状态与对比状态测试通过，MkDocs 严格构建通过。实际浏览器检查了五种视图、缩放分离、搜索、独立详情跳转与返回状态恢复、坐标框裁切和窄屏页面宽度。

默认坐标视图仍收录 85 款手和 1 个系统。自由度分组、手指构型、传动路线默认总览各有 86 个独立产品标签；驱动规模 57 条可定位、29 条待核；主动轴演进 52 条可定位、34 条待核。放大后仅渲染当前视野内的标签，其余产品通过拖动地图继续查看。

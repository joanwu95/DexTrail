## 深入核查：规格测量对象

核查：2026-10-02；仍为 partial。参考 [SCHUNK 2008-04-10 数据表，NIST 保存](https://www.nist.gov/document/9020173r1pdf)。文件由厂商署名，托管于 NIST 不意味着 NIST 独立测得这些参数。

| 指标 | 数据表内容与边界 |
|---|---|
| 机构 | 3 指、每指 2 主动轴，加两指共用的反向展开轴，总计 7 主动轴 |
| 尺寸重量 | 全长 253 mm、指长 155 mm、指根距 66 mm；整重 1.95 kg |
| 力矩 | 近端关节 2.1 N·m、远端 1.4 N·m；是关节力矩，不是指尖力 |
| 速度 | 最大关节角速度 210°/s；负载及持续时间条件未在此单页展开 |
| 感知 | 7 绝对编码器、6 触觉阵列；6 指阵列块数，不是总触点数量 |
| 通信 | CAN、Ethernet、RS232；并未在此给出控制周期 |
| 防护 | IP65 前标注 aim，即设计目标，不能写成已获得防护认证 |

工程解释：两指共用展开轴可改变抓握布局，但不能分别任意调整二者展开角。分布在指节的触觉有助于识别接触区域；要比较力测量能力，还需阵列触点数、标定、采样和饱和范围。

找到 [ETFA 2014 操作研究入口](https://upcommons.upc.edu/bitstream/handle/2117/26542/etfa14-ms.pdf)，但全文请求失败，暂不转述其定量结论。SDH 专用 SDK/仿真版本、材料、独立重复试验仍待核验；SVH 的 MuJoCo 模型是另一款五指手，不能当作 SDH 资源。

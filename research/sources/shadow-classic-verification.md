# Shadow Classic 首轮来源核验

核验日期：2026-10-01。结构化来源以 data/sources.yaml 为准。

## 采用范围

- 产品：Classic 五指电驱版，保留 shadow-hand 稳定 ID。
- 基准：December 2024 官方规格书，配合当前官方系列页的 Classic 列。
- 排除：Lite、Extra Lite、Super Lite、DEX-EE、早期气动版。
- 论文：只核验 OpenAI arXiv:1808.00177v5 摘要和版本信息，未全文复现。
- 仓库：sr_common 的 noetic-devel 分支，未锁定提交，未运行。

## 保留未知

发布年份、尺寸、材料、价格、交期、耐久性，以及当前 ROS / 仿真环境兼容性。
规格书版本日期不能当成产品发布年份。完成资料核验不代表独立性能验证。

# 分类地图覆盖与 Sudo R1 修正

## 原因与修正

复现确认：02 和 03 按钮能够切换坐标，并非完全没有响应。实际问题是 64 款手中，只有 24 款能按主动关节角 × 执行器数定位，18 款能按传动机制 × 主动关节角定位。其余记录只藏在抽屉中，用户难以发现新增档案。

现在所有坐标缺失档案在地图下方直接展示，说明已知参数和无法定位的原因。数值轴保留原有定义，不把总机械自由度、气动腔数、协同输入或未知传动强行变成主动关节角和确定类别。

Sudo R1 之前只有静态系统介绍，没有接入首页地图。本次增加 `data/related-systems.json`，由构建钩子输出 `systems` 集合，和手部档案一起参与搜索、定位和坐标待核展示。统计为 64 款手 + 1 个系统；不把整套 R1 冒充独立手本体。

## 媒体纠正

移除了 IMG_0139_1.webp。官网将它用于评估物体片段缩略图，不能当作 R1 硬件照片。

页面不再使用图片或海报，用原生视频播放器与必要时的 HLS.js 播放官方流。7 个选项分别为系统演示、连续评估、不同视觉条件、干扰响应、受限空间、杂乱抓取、仿真。最后一个明确标为仿真，不当作实物演示。

官方来源：https://www.sudo.ai/ 。具体地址保存在 `sudo-r1-videos.json`，提取自本轮官网 HTML 的播放器配置，未猜测媒体路径。没有把视频下载到仓库。

# 三个视觉方向
视觉图鉴的布局已用于首页；工程解读与路线地图已接入首页浏览路径。A 页保留作最初方案对照，产品证据仍来自原有数据库。
- [A 视觉图鉴](gallery.html)：暖灰展陈背景、衬线标题、大幅外观与动作演示。
- [B 工程解读](anatomy.html)：暗色研究台、明亮产品画面、问题驱动的证据阅读。没有内部剖面证据，暂不做解剖标注。
- [C 路线地图](routes.html)：自然色路线分区，以产品为入口，分构造、感知和学习探索。
三种视图均支持窄屏，点击后可查看真实来源或进入已有详情页。
图片和视频远程引用作者/厂商页面，仅作本地视觉评估；不下载，不意味着获得再分发授权。正式发布前须核对媒体授权。离线时显示来源入口。
数据快照通过项目根目录运行 `python scripts/build-visual-samples.py` 更新；从同一份 YAML 提取 Shadow 和 LEAP，不单独维护规格。

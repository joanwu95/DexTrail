厂商为英国 Shadow Robot Company。规格版本日期不作为首次发布年份；首次发布时间仍待追溯。以下为官方系列对比表的 Classic 列，不混用其他版本。

|---|---|---|
| 手指与运动轴 | 五指；20主动自由度、24关节 | 有些关节联动，不能发24个独立关节命令 |
| 腕与手掌 | 两个腕关节；小指侧掌部可弯曲 | 对比不含腕部的手时，应分开统计 |

## 感知与控制：到底测到了什么

下面集中概括[2024规格书 §2–5](https://shadowrobot.com/wp-content/uploads/2024/12/shadow_dexterous_hand_e_technical_specification_20241204.pdf)，数值属于厂家规格。

| 项目 | 具体内容与边界 |
|---|---|
| 重量与承载 | 4.3 kg含前臂；4 kg承载限于包络式力量抓握，不是单指负载 |
| 位置 | 霍尔测角，典型分辨率0.2°；分辨率不是定位精度 |
| 触觉 | 拇指、食指STF各17个三轴感测单元，输出未标定数据 |
| 腱负载 | 电机端腱对负载用于力矩环；约30 mN分辨率，调零但未标定；零值指腱间差值为零 |
| 频率 | 电机力矩环5 kHz；主机环1 kHz；腱力典型上报500 Hz，电流/温度100 Hz |
| 默认控制 | 主机位置控制，电机端PID；开放接口允许其他控制策略 |

**工程解释**：可以把腱线想成拉动手指的绳子。知道绳子拉得多紧，还要结合关节姿态、传动摩擦和接触位置，才可能估算物体受力；不能把腱读数直接叫“指尖接触力”。调零只改变参考点，标定才建立读数与物理量的对应。

触觉单元反映指腹受压时内部磁场的变化；得到三轴信号，也不意味着未经标定就能输出准确的三维接触力。电流、温度用于观察执行器状态，不能替代接触传感。视觉融合需要外部视觉系统；本轮没有确认掌内相机配置。

**工程解释**：控制环频率是算法更新速度，传感上报频率是新数据抵达速度。上层程序跑得更快不会凭空产生新测量。官方允许自定义控制，不代表已经交付针对某种任务调好的阻抗控制、MPC或强化学习策略。

## 操作能力与研究评价

[OpenAI：Learning Dexterous In-Hand Manipulation](https://arxiv.org/abs/1808.00177v5)的摘要报告在仿真随机化摩擦及视觉外观等条件，用强化学习训练后迁移到实物Shadow完成视觉辅助的物体重定向，并观察到换指和多指协调。初稿为2018年，v5为2019年。

这是第三方研究团队的系统实现，支持“该平台曾用于实物手内操作研究”，不能证明2024配置自带该能力。本轮仅核对该论文摘要，未补完全文的试验次数、失败统计、传感装置和硬件修订，暂不填成功率。论文页面提供作者视频入口；视频是演示证据，不替代实验协议。

## 优势、代价与适用任务

以下为基于上述来源的工程解释：

- **仿人运动研究**：五指、腕和掌部运动提供较丰富的姿态选择，适合研究动作映射；代价是需要处理更多关节、耦合与标定关系。
- **感知控制研究**：关节、腱负载和触觉是不同层次的观测，有利于对比不同反馈来源；必须先处理标定和采样时序。
- **仿真开发**：已有ROS/Gazebo与MJCF入口，能从模型开始实验；真实腱传动和仿真执行器的差异仍需辨识。
- **移动平台集成**：应按手与前臂整体核算安装、惯量和供电；不能把整体重量与其他产品仅手掌部分的重量直接排行。

本轮未找到可直接用于统一比较的第三方寿命、维护周期及当前采购成本数据，不写“贵、脆弱、工业成熟”等无条件结论。

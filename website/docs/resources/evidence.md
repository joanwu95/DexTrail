# 来源与核验规范

## 区分三类陈述

- **事实**：参数或能力必须链接支持该陈述的具体来源，注明型号与版本。
- **文献报告的局限**：保留实验对象、条件和适用范围。
- **工程解读**：说明依赖的证据、假设与尚未验证的推断。

来源优先级：官方文档、同行评审论文、技术报告、代码仓库、会议视频、社区讨论。来源类型并不等于结论已独立验证。

## 参数与能力

参数没有证据时保留未知。主动驱动数量、总自由度和被动自由度分别核对，避免混用。

技术关联区分 **官方支持**、**文献实现**、**本人验证**。一篇论文实现某种控制方法，不代表厂家默认提供它。

## 来源记录

每条记录包含标题、原始 URL、类型、版本与核验日期。产品的每个参数、技术关联和评价通过来源 ID 引用证据。图片、视频与大型资源以 URL 管理，并记录授权；不自动下载。

核验日期表示最近一次检查来源的时间，不是发布时间。

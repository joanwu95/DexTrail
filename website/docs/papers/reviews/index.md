<details class="evidence-drawer" markdown="1">
<summary>收录标准与阅读范围</summary>

收录明确自称 Review 或 Survey、且直接讨论机器人手或多指灵巧操作的文献；一般机器人综述只有与该主题直接相关时才收录。原始依据优先使用出版机构与作者预印本页面。

每篇的“阅读建议与书目信息”标明实际核验范围。当前导读以摘要和指定章节为依据，后续可逐篇补充全文解读。预印本的收录版本不表示已获期刊或会议录用。综述帮助定位研究，具体性能仍需核对原始实验论文。

</details>

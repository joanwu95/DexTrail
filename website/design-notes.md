# DexTrail 页面视觉约定

## 方向与颜色

保留深空技术地图的黑色背景 `#0d0e11`、金色导航 `#e5bd78`、低对比细线 `#292e37`。详情页采用适合长篇技术阅读的排版：正文灰白、标题亮白、金色用于链接和选中状态。

## 字体与层级

沿用 Segoe UI / Noto Sans SC / Microsoft YaHei 无衬线字体栈。等宽字体仅用于需要对齐的数据读数；不再用英文小标题与装饰编号强调技术感。

- 首页与详情共用品牌变量：桌面字标 44px / 600，图标 51px；600px 以下字标 36px、图标 42px。
- 产品标题 28–40px / 600；完整技术记录标题 28px；章节标题 23px；小节标题 20px。
- 长文正文 16px / 400，行高 1.9；表格 15px，预览面板文字 15px、表格 14px。
- 辅助说明 13–15px。链接继承所在文字的字号，不单独缩小；强调文字用 600 字重。

## 布局

首页和详情使用相同的自适应页面边距。详情上方保留媒体与技术面板双栏，小屏改为单栏；完整技术记录使用左侧章节索引和右侧正文。长段文字限制行长，表格使用可用宽度。

## 组件

地图、媒体、技术预览与专题内容使用开放布局：通过间距、对齐和标题建立分组，不为每个模块套矩形外框。边界留给输入框、数据表和浮动面板；地图坐标、节点、深色与金色品牌、彩色标签沿用既有设计。移除常驻操作日志和缩放尺装饰，保留缩放按钮及倍率。

所有已发布产品共用详情模板；独立技术报告、首轮分析与数据库/资料目录也使用同一深色页面。目录通过开放的文字列表展示，不套卡片外框。报告正文及原始来源由原文件生成，避免为视觉修改复制或重写证据内容。产品数量从发布数据计算。

数据库与技术资料目录支持名称/关键词检索；`directory.js` 直接筛选服务器生成的完整列表，不维护额外的产品副本。桌面两列、手机单列，匹配数与空结果通过状态文本提示。全量覆盖记录见 `../research/notes/open-layout-coverage.md`。

统一品牌图标尺寸、字距和图文间隔。技术维度与图片选择使用文字导航、选中下划线和键盘焦点状态，小屏自动换行。数据表通过表头底色、行分隔与单元格留白区分层级，宽表在容器内部横向滚动。图片选择、来源链接和原始笔记沿用同一套颜色与字重。

## 浏览连续性

同一浏览器标签内，返回地图恢复分类、搜索、缩放和平移位置。地图状态仅存在会话存储中；存储不可用时仍可正常浏览。技术维度默认悬停或键盘焦点预览，点击后固定；通过“恢复悬停浏览”解除固定。切换维度保留各自的阅读位置与已展开来源，重复选择当前维度不重置内容。
